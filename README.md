Collection app.

• See a list of all the movies in his collection
• Update movies in his collection
• Delete movies from his collection

fields (Title, Year, Edited, CopiedToPlex). The user should also not be allowed to
enter a year lower than 1888 (the year the first movie came out.)

variable names, etc.)
